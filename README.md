# OSMOSE_EEC_SA
Sensitivity analysis of OSMOSE-EEC

Please cite
"Global sensitivity analysis of a complex marine ecosystem model: Advancing the understanding of ecosystem functioning"
[Yansong Huang et al., 2026](https://doi.org/10.1016/j.ecolmodel.2026.111725)

The code is developed based on the work "Key species and indicators revealed by an uncertainty analysis of the marine ecosystem model OSMOSE" [Criscely Luján et al., 2024](https://doi.org/10.3354/meps14465)
